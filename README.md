# ⌨️ タイピングノート

おんたまドリルの タイピング練習アプリ。キーボードの **ゆびの ばしょ（ホームポジション）** を
おぼえながら、たまごを かえして ひよこを あつめます。

公開先（予定）: <https://hot-spring-egg.github.io/typing-note/>

## できること

- **ステージ（23こ）**：ホームの だん → うえの だん → したの だん で キーを 2つずつ、
  さいごに ローマじで ことば。クリアすると たまごが かえり、★の数で 🐣 → 🐤 → 🐥 と そだつ
- **ホームポジション確認**：はじめる前に F と J を いっしょに おさないと スタートしない
- **て の え**：手の こうを 上から見た シンプルな 手。ゆびごとに 爪の色を かえ、
  つぎに うつ ゆびは 色の ふちどりで ぴょんと はねる。キーボードも ゆびごとに 色分け
- **まちがえたとき**：「おしたのは K（みぎの なかゆび）。F は ひだりの ひとさしゆび だよ」と教える。
  けっかに「にがてな キー」
- **たまごキャッチ**：おちてくる たまごの キーを うって おんせんに 入れる 60びょうの ゲーム
  - 10びょう ごとに **レベルアップ**（Lv.1〜6）。おちる はやさ・でてくる かず・いちどに でる かずが ふえ、
    空の いろも あおぞら → ゆうやけ → ほしぞら と かわる
  - 10れんぞくで **フィーバー ×2**、25れんぞくで **×3**（キーの まちがい・たまごを わると おわり）
  - とくべつな たまご：✨きん（3ばい）・❤️ハート（❤️が 1つ ふえる）・⏱とけい（じかん +5びょう）
  - さいごの 10びょうは **ラストスパート**（きんの たまごが ふえる）
- **ためしうち**：すきな キーを おすと、その キーを うつ ゆびが 光る
- せってい：おと／キーボードを みないで うつ／ぜんぶの ステージを ひらく（先生向け）

入力は `KeyboardEvent.code`（キーの 場所）で 判定するので、日本語入力が ON でも
CapsLock でも うてる。ローマ字は し=shi/si、ん=n/nn、っ=子音2つ/xtu など よくある 打ち方を みとめる。

## おんたまドリルの スコア

`ontamaScore.js` で、ポータルと 共有している `localStorage` の `gogo_drill_score` に たす
（`hot-spring-egg.github.io` の 同じオリジンに 置くこと）。

| | ポイント |
| --- | --- |
| ステージクリア | ★1：10 / ★2：15 / ★3：20 |
| たまごキャッチ | キャッチした たまご 2こで 1ポイント（1回 最大40。フィーバーの ばいは ふくめない） |

このアプリの 記録は `ontama_typing_note_v1` に 保存。「きろくを けす」でも
ポータルの スコア（`gogo_drill_score`）は 消えない。
